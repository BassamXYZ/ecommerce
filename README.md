## Run Locally

Clone the project

```bash
  git clone https://github.com/BassamXYZ/ecommerce.git
```

Go to the project directory

```bash
  cd ecommerce
```

Install dependencies

```bash
  pip install -r requirements.txt
```

Start the server

```bash
  python manage.py runserver
```
